# 简体中文

## Promotional Text
按自己的方式分享位置。选择 Miataru 服务器、信任的设备和适合你的定位功能。

## Description
使用 miataru，自主决定如何分享位置。选择要使用的 Miataru 服务器，添加信任的设备，并按需启用位置分享和跟踪功能。

在互动地图上查看多台设备，了解距离以及电量、海拔、速度和地点等可用信息，并将设备分组。你可以通过二维码、链接或手动添加设备。规划路线时可查看距离、预计用时、到达时间和转向提示。还可切换到高对比度全屏导航视图，并选择是否镜像显示。

可选择在前台或后台分享位置，并选择省电或更频繁的位置更新。如果服务器支持，还可将访问限制为获准设备。你也可以查看最近的位置请求，并选择是否接收陌生访客提醒。

为选定设备使用小组件，并通过 Siri 或快捷指令查询设备最近一次已知位置或路线。miataru 专为 iPhone 和 iPad 设计，并提供 iPad 专用布局。位置分享受服务器、设备设置、权限和网络连接影响。

## What's New
路线前往某台设备时，导航会显示自己的速度；路线从某台设备前往你的位置时，会显示该设备的速度。没有有效速度值时，会隐藏速度显示。
