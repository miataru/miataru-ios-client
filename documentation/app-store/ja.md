# 日本語

## Promotional Text
自分のルールで位置情報を共有。Miataruサーバー、信頼できるデバイス、必要な位置情報機能を選べます。

## Description
miataruなら、位置情報の共有方法を自分で決められます。利用するMiataruサーバーを選び、信頼できるデバイスを追加して、必要な共有・追跡機能を選択できます。

複数のデバイスを地図で確認し、距離やバッテリー、高度、速度、場所などの情報を表示できます。デバイスはグループに整理でき、QRコード、リンク、手入力で追加できます。距離、所要時間の目安、到着時刻、ルート案内を含む経路を計画できます。高コントラストの全画面ナビゲーション表示に切り替えられ、表示の左右反転も選べます。

位置情報はアプリ使用中またはバックグラウンドで共有できます。省電力の更新頻度や、より頻繁な位置情報の更新を選べます。サーバーが対応している場合は、許可したデバイスだけにアクセスを制限できます。最近の位置情報リクエストを確認し、不明な訪問者の通知を受け取るかどうかも選べます。

選択したデバイスのウィジェットを使い、Siriやショートカットにデバイスの最終確認位置や経路を尋ねられます。miataruはiPhoneとiPad向けに設計され、iPad専用レイアウトも備えています。位置情報の共有は、サーバー、端末の設定、許可、ネットワーク接続状況によって異なります。

## What's New
デバイスへ向かうルートでは自分の速度を表示します。デバイスから自分へ向かうルートでは、そのデバイスの速度を表示します。有効な速度がない場合は表示されません。
